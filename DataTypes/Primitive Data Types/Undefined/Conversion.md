

## **`undefined` to Number**

- **Conversion**: When `undefined` is converted to a **number**, it becomes `NaN` (Not-a-Number).
    
```jsx
let x = undefined;
console.log(Number(x)); // NaN
```


## **`undefined` to Boolean**

- **Conversion**: When `undefined` is converted to a **boolean**, it becomes `false`.
    
```jsx
let x = undefined;
console.log(Boolean(x)); // false
```


## **`undefined` to String**

- **Conversion**: When `undefined` is converted to a **string**, it becomes the string `"undefined"`.
    
```jsx
let x = undefined;
console.log(String(x)); // "undefined"
```
