# Escape Characters in JavaScript

| Escape Sequence | Description     | Example Code                        |
|-----------------|-----------------|-------------------------------------|
| `\n`            | New line        | `let str = "Hello\nWorld";`         |
| `\t`            | Tab             | `let str = "Hello\tWorld";`         |
| `\'`            | Single quote    | `let str = 'It\'s a test';`         |
| `\"`            | Double quote    | `let str = "He said, \"Hello!\"";`  |
| `\\`            | Backslash       | `let str = "This is a backslash: \\";` |

```jsx
let str = "He said, \"BSPrince47!\"";
```
