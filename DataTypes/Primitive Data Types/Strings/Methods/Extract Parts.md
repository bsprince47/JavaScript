# Extract Parts of String



### slice()
Extracts a part of the string (can use negative indices).
    
```jsx
console.log(str.slice(7, 12)); // 'World'
```
    
### substring()
Extracts a part of the string (does not accept negative indices).
    
```jsx
console.log(str.substring(7, 12)); // 'World'
```
    
### substr()
Extracts a substring based on start index and length (deprecated).
    
```jsx
console.log(str.substr(7, 5)); // 'World'
```
