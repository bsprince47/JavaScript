# String Conversion in JavaScript

### String()

```jsx
console.log(String(123)); // '123'
```
    
#### toString()
    
```jsx
let num = 456;
console.log(num.toString()); // '456'
```


### Objects to strings:

```jsx
let obj = { name: "John" };
console.log(String(obj)); // '[object Object]'
```
    
### Booleans to strings:
    
```jsx
let bool = true;
console.log(bool.toString()); // 'true'
```
