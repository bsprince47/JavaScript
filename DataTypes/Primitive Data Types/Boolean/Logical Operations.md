

# Boolean Logical Operations in JavaScript

### **a. AND (`&&`)**

- Returns `true` if both operands are true.
    
    ```jsx
    let isLoggedIn = true;
    let hasAccess = true;
    console.log(isLoggedIn && hasAccess); // true
    ```
    

### **b. OR (`||`)**

- Returns `true` if at least one operand is true.
    
    ```jsx
    let isWeekend = false;
    let isHoliday = true;
    console.log(isWeekend || isHoliday); // true
    ```
    

### **c. NOT (`!`)**

- Negates the value.
    
    ```jsx
    let isVisible = false;
    console.log(!isVisible); // true
    
    ```
